# Excel_dashboard_project
# 🏏 Cricket Data Analysis Dashboard (Excel)

## 📌 Project Overview
This project is an **interactive Cricket Data Analysis Dashboard** built using **Microsoft Excel**.  
It transforms raw cricket match data into meaningful insights through dynamic visualizations and filters.

The dashboard allows users to explore player and team performance across different matches using slicers and charts.

---

## 🎯 Objectives
- Analyze cricket player performance (Runs, Wickets, Economy, Boundaries)
- Compare teams and players dynamically
- Create an interactive and user-friendly dashboard
- Practice data analytics and visualization using Excel

---

## 📊 Features
- 🔹 Interactive **Slicers**:
  - Match ID
  - Team
  - Player Name
  - Fours
  - Sixes  

- 🔹 Dynamic Charts:
  - Player performance comparison
  - Runs vs Economy analysis
  - Team-wise statistics
  - Boundary (Fours & Sixes) analysis  

- 🔹 Clean and structured dashboard layout
